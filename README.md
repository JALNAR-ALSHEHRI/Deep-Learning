# Deep Learning

This repository contains deep learning projects developed using modern neural network architectures for solving real-world problems. The projects explore different deep learning techniques for prediction, classification, sequence modeling, and representation learning.

## Topics Covered

* Artificial Neural Networks (ANN)
* Convolutional Neural Networks (CNN)
* Recurrent Neural Networks (RNN)
* Long Short-Term Memory (LSTM)
* Temporal Convolutional Networks (TCN)
* Attention Mechanisms
* Model training and evaluation
* Performance analysis

## Tools & Technologies

* Python
* TensorFlow
* Keras
* PyTorch
* NumPy
* Pandas
* Matplotlib

## Repository Structure

Each project is organized in a separate folder and includes:

* Source code
* Jupyter notebooks
* Model implementation
* Training and evaluation results
* Visualizations
* Project-specific documentation

## Purpose

This repository showcases deep learning projects developed to strengthen practical experience in neural networks and artificial intelligence while building solutions for real-world applications.
